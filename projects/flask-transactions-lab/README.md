# Flask Transactions Lab

A learning project based on an IBM/Coursera Skills Network lab.

## Features
- List transactions.
- Add a transaction.
- Edit a transaction.
- Delete a transaction.

## Skills practiced
Flask routes, HTML templates, handling form submissions,
and working with Python lists and dictionaries.

## Troubleshooting lessons
- Run commands from the folder containing app.py.
- Use __name__ with two underscores on each side.

## Limitations
Transactions are stored in memory, not a persistent database.
This is an educational application.
