# Notebooks

This folder contains exploratory analyses, course laboratories, and healthcare data-science notebooks.

## Naming Convention

Number notebooks in the order they are completed:

- `01_logistic_regression_diabetes.ipynb`
- `02_next_project.ipynb`

Before committing a notebook:

1. Restart the kernel.
2. Run every cell from top to bottom.
3. Confirm that the notebook runs without errors.
4. Remove patient information, passwords, tokens, and confidential data.
